ClipNotes

clip a note to anything

Clip the page you are reading plus a note of your own into a private notebook inside Chrome. Everything stays in your browser: search across clips and notes, and JSON or Markdown export you own. Page text is only captured when you press the button.

Download ZIP

What it does

  • "Clip this page" saves the current page — title, URL and readable text — into your private notebook in chrome.storage.
  • Every clip has its own note box: write your thoughts under the page and save them with the clip.
  • "Blank note" starts an empty note for ideas that have no page yet — search covers clips, URLs and notes together.
  • Export the whole notebook as Markdown or JSON, a file you own and can open anywhere.
  • The notebook is capped at 300 notes so storage stays light; the oldest notes are pruned first.

Permissions — minimal and used

  • storage — your notebook and language live only in chrome.storage.local.
  • tabs + activeTab + scripting — reading page text only for the tab you clicked on: tries a plain fetch first, and only when that fails uses Chrome's read-the-active-tab API.
  • No host permissions: no site ever gets persistent access to this extension.
Honest note: page text is captured at the moment you click the button, not continuously. When a page cannot be read, ClipNotes saves the title and URL only, so your note is never lost.

Install

  • Download clipnotes.zip and unpack it somewhere permanent.
  • Open chrome://extensions and enable Developer mode.
  • Click "Load unpacked" and pick the folder (keep the folder after loading).
  • Open the popup on any page you want to keep, click "Clip this page", and add your note.
